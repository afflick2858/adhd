# Your First Video: V01 in CapCut, Click by Click

This is the one-time detailed version. After V01, the short workflow in `content-strategy.md` is all you'll need. Time budget: ~30 min for this first one, ~10–15 min once familiar.

**What you're making:** a 40-second faceless Reel — AI voice reads the script while stock b-roll plays with bold captions. Watch `marketing/hvac/video-drafts/V01-draft.mp4` first: it's a rough text-only preview of the pacing and on-screen text you're about to build (your finished version adds voice + b-roll on top of exactly this skeleton).

## Setup (once, ever)

1. Go to **capcut.com** → sign up free (or install the desktop app — same steps, more screen room than mobile).
2. Open `marketing/hvac/content/week-01/V01-your-hvac-business-is-leaking-3k.md` side-by-side.

## Step 1 — Project

- **Create project** (desktop: "New project"). Set aspect ratio **9:16** (portrait) — button is in the right-hand panel or under "Ratio."

## Step 2 — The voice (this is the backbone)

1. Left toolbar → **Text** → **Add text** (a default text box appears on the timeline).
2. Paste the ENTIRE voiceover script from V01's "Full voiceover script" section into the text box.
3. With the text selected, find **Text-to-speech** in the right panel → browse voices → pick a natural US voice you like (aim for calm/confident, not radio-announcer).
   **Write down which voice you picked. Use it for all 39 videos. Never change it.**
4. Click **Generate/Apply** — an audio clip appears on the timeline (~40s).
5. **Delete the text box** (keep the audio). The voice track is now your timing ruler.

## Step 3 — B-roll (the visuals)

V01's shot-by-shot table has 8 rows. For each row:

1. Left toolbar → **Media → Library** (CapCut's free stock) → search the row's b-roll terms (e.g. `hvac technician air conditioner repair`).
2. Drag a clip onto the timeline; trim it to the row's time window (0–2s, 2–7s, …) by dragging its edges. Clips butt up against each other — hard cuts, no transitions needed (fast cuts are the style).
3. Can't find a good clip? Second source: **pexels.com** → search the same terms → free download → drag the file into CapCut media.
4. Last row (35–40s) is a solid-color end card: **Media → Library → search "navy background"** (or Text-only on a colored background) with the big text "5 leaks. 5 weeks. FOLLOW ⬆".

## Step 4 — On-screen text

For each table row's "On-screen text": **Text → Add text**, type it, style it **bold white, ~2/3 down the screen**, and stretch its timeline bar to match that clip's window. For the five "LEAK n" moments, make the numeral big and let it pop in (any preset "pop" animation under Text → Animation).

## Step 5 — Captions + music

1. **Captions → Auto captions → Generate** — CapCut transcribes the AI voice. Pick a bold template; set highlight color to yellow for the dollar figures (tap a caption → edit word color).
2. **Audio → Music** → search "minimal hip hop instrumental" → drag under the voice → lower its volume to ~10% (click clip → volume).

## Step 6 — Export + post

- **Export**: 1080p, 30fps, mp4. Filename `V01.mp4`.
- Post the same file to: FB Reels, IG Reels, YouTube Shorts, TikTok. Caption + hashtags: copy from the V01 file's "Post caption" and "Hashtags" sections.

## Quality checklist before export

- [ ] Voice audible and captions match it
- [ ] A visual change at every leak number (keeps retention)
- [ ] Dollar figures visible on screen when spoken
- [ ] Music barely audible under the voice
- [ ] First 2 seconds: hook text on screen immediately (no logo intro, ever)
